## 詳細調查

### 1. 議員名單與選區

- **來源**：`https://www.tcc.gov.tw/cp.aspx?n=13898`（現任議員名錄，依 `qtype=1..8` 對應第1–6選區＋原住民選區等分頁）
- **實測**：`curl -o /dev/null -w "%{http_code}"` → `200`。頁面為傳統 ASP.NET（`cp.aspx`）後台輸出的 HTML，非 API。
- **格式**：HTML，需解析表格／清單結構；欄位預期含姓名、選區、黨籍、辦公室聯絡方式。
- **更新頻率**：隨遞補、辭職即時異動（無法確認更新延遲）。
- **授權／Key**：無需 Key，公開網頁；未見開放資料授權條款（政府網站慣例上多為可重製引用，需查頁尾聲明，未逐一確認）。
- **已知坑**：ASP.NET (`.aspx?n=...`) 頁面高度依賴內部頁面編號（`n=`），編號無規律、無版本化 API，網站改版會使連結失效；需人工定期巡檢。另有「歷屆議員查詢」`Councilor_Search1.aspx?n=13869`（未實測，僅由導覽結構取得）。
- **黨籍、辭職遞補**：本次未查到獨立的「異動紀錄」頁面或 API；只能比對議員名錄頁面的歷史快照，或查新聞稿／中選會公告。維基百科「臺北市議員列表」可作為交叉核對的輔助來源（非官方，未實測）。

### 2. 出席紀錄

- **未找到**任何獨立的「出席／請假」結構化資料庫、頁面或 API。
- 依《臺北市議會議事規則》（`https://w2.dbas.gov.taipei/RULE/A/A7.pdf`，僅由搜尋結果得知連結，未實測下載），議事錄格式應記載出席人數／請假人數／缺席人數，但這些資訊藏在議事錄全文（PDF/HTML）內，須逐份解析。
- **狀態**：僅文件宣稱存在（規則要求記錄），實際擷取需自行解析議事錄全文，成本高、格式可能逐屆不同，未實測解析可行性。
- **缺口**：這是六都議會的通病——出席不像立法院有專門的「院會出席」開放資料，臺北市議會目前看不到對應物。

### 3. 質詢紀錄

- **主要來源**：臺北市議會電子公報全文檢索系統
  - 舊網址：`https://gaz.tcc.gov.tw/`
  - 搜尋結果頁：`https://gaz.tcc.gov.tw/search/dq/deptID/result.html?sort=desc&sortField=date`
  - 搜尋結果另指出可能已遷移至新網域 `https://tcckm.tcc.gov.tw/`（由 Google 搜尋結果得知，本次僅實測 `gaz.tcc.gov.tw`，新網域未 curl 驗證，需後續確認兩者關係——是否為新舊並行或已切換）。
- **實測**：`curl https://gaz.tcc.gov.tw/` → `200`，回傳完整 HTML（含 CSS/JS 前端框架）。
- **查詢欄位**（經 WebFetch 讀取頁面確認）：議員姓名、關鍵字、局處別（民政、財政建設、教育、交通、警政衛生、工務等）、文件類型（書面質詢、會議紀錄、速記錄、市府書面報告）。
- **結果欄位**：日期＋局處（如「115-09-24 民政」，民國紀年）、屆別會期（如「第14屆第08次定期大會」）、標題、提案議員、內容摘要、PDF 連結。
- **資料量**：頁面顯示「共24,949筆資料」，涵蓋歷史累積筆數（非僅本屆）。
- **格式**：HTML 檢索介面＋逐筆連結至 PDF 全文（「另開視窗」開啟文件檢視器）。**非 JSON API**，無官方介接文件；如要程式化擷取須做 HTML 爬蟲＋PDF 解析。
- **robots.txt**：`curl https://www.tcc.gov.tw/robots.txt` 與 `gaz.tcc.gov.tw` 皆回傳自訂 404 頁面（非標準 robots 內容），即**站台未發布 robots.txt**，未見明文禁止爬取，但也無明文授權——需以一般政府網站合理使用原則處理，且注意頁面結構穩定性未知（ASP.NET 前台，版面可能隨改版變動）。
- **市政總質詢 vs 部門質詢 vs 書面質詢**：查詢頁的「文件類型」篩選可分「書面質詢」等類別，口頭質詢（市政總質詢、部門質詢）紀錄則應在「會議紀錄／速記錄」類別中，需要交叉比對日期與屆期，未逐筆驗證分類是否乾淨可靠。

### 4. 質詢影片連結

- **來源**：
  - 歷史影音：`https://tccvideo.tcc.gov.tw`（已實測 `200`）
  - 即時直播：`https://live.tcc.gov.tw/`（已實測 `200`）
- **經 WebFetch 讀取頁面**：搜尋條件為「依日期」「依屆次」與影片類型（專案報告、工作報告、施政報告、部門質詢、市政總質詢等）。**頁面文字未顯示可依「議員姓名」直接搜尋**（與公報系統不同）。
- **是否可取得單支影片 URL**：頁面文字未明確揭露搜尋結果的 URL 格式，也未確認是否有可分享的單支影片直連（可能是內嵌播放器、需點擊進入才產生 session-based URL）。**此項為僅文件宣稱／未驗證，需要實際操作瀏覽器點擊測試（非純 curl 可判斷），建議下一步用瀏覽器工具實際跑一次「日期＋部門質詢」查詢並記錄產生的影片頁 URL 結構**。
- **YouTube 頻道**：本次搜尋未特別確認臺北市議會官方 YouTube 頻道是否存在／是否同步全部質詢影片，待補查。

### 5. 提案、議事錄、公報

- **來源**：`www.tcc.gov.tw` 的 `MeetingMinutes.aspx` 系列頁面：
  - 議事錄：`?n=13534&kind=2`
  - 速記錄：`?n=13535&kind=3`
  - 市府書面報告：`?n=13537&kind=1`
- **實測**：`curl -L https://www.tcc.gov.tw/MeetingMinutes.aspx?n=13534&kind=2` → `200`。
- **格式**：HTML 列表頁，逐筆應連結至 PDF 全文（未逐筆點入驗證 PDF 是否可下載）。
- **公報系統**：同第3項的 `gaz.tcc.gov.tw`，「會議紀錄」類別也涵蓋公報全文檢索。
- **提案（議案）查詢**：本次未特別找到獨立「議案追蹤」頁面（如立法院的「法律提案」系統），僅在會議紀錄／速記錄中可能包含提案內容，需另行確認是否有獨立議案系統（例如「議案管理系統」），本次未查證，列為缺口。

### 6. 市長政見與兌現追蹤

- **官方**：透過 WebSearch 找到「臺北市政府全球資訊網」新聞稿提及市府研考會彙整施政成果、由都市再生／務實交通／幸福育兒／長者關懷等面向盤點政見執行進度（例：`https://news.pchome.com.tw/public/pronews/20260522/index-77945942700158353016.html` 提及「蔣萬安揭台北重大施政 多面向政策進度一次總盤點」）。**這是新聞稿層級的敘述，不是結構化、可查詢的政見追蹤資料庫或 API**。
- 搜尋研考會官網是否有獨立的「市政計畫進度管理系統」公開版：本次未查到，需後續針對 `https://rdec.gov.taipei` 或研考會網站另行確認（僅提及台北市研考會滿意度民調 `FTNN` 報導，非政見追蹤系統本身）。
- **第三方（媒體／g0v／公民團體）**：WebSearch 未找到現成、持續維護、鎖定「2022蔣萬安政見 vs 兌現進度」的獨立追蹤網站或資料集。g0v 生態中查到的相關舊專案（如 `councilor-voter-guide`、`councils.g0v.tw`）多聚焦「議員」出席／提案／預算比較，並非市長政見兌現追蹤，且未確認目前是否仍在維護、是否涵蓋臺北市第14屆。
- **狀態**：這是本次調查中**最大的缺口**——沒有可實測、可介接的市長政見兌現資料源，civic-lens 若要做這塊，很可能得自建（人工整理政見文本＋逐項比對新聞稿／市府公告）。

### 7. data.taipei 資料大平臺

- **API 端點**：`https://data.taipei/api/v1/dataset/search?q=<關鍵字>&limit=<n>`
- **實測**：
  - `q=議員`、`q=議會`、`q=出席`、`q=質詢`、`q=政見` → 全部回傳 `{"result":{"limit":20,"offset":0,"count":0,"sort":"","results":[]}}`（HTTP 200，JSON，但 `count:0`）
  - 舊格式 `api/v1/dataset?scope=resourceAquire` → `404`（此路徑格式已失效或錯誤，正確格式應為 `dataset/search`）
- **結論**：data.taipei 平臺上**目前沒有**與臺北市議會（議員、出席、質詢）或市長政見相關的資料集。這是已實測確認的「不存在」，不是未查到。
- **格式／授權／Key**：API 免 Key、回傳 JSON，符合 data.taipei 一般開放資料規範（政府資料開放授權條款，未逐條核對版本）；但無相關資料集可用，此路徑對本專案暫無實質幫助。

## 缺口與風險總結

1. **出席紀錄無結構化來源**：六都普遍缺乏，臺北市亦然；只能從議事錄全文反推，解析成本高、格式易變動，需先做小規模 PoC 驗證解析可行性再決定是否投入。
2. **質詢影片能否依「議員＋日期」精準取得單支 URL 未驗證**：`tccvideo.tcc.gov.tw` 頁面未明示按議員搜尋，也未確認單支影片 URL 的產生方式；需要實際瀏覽器操作驗證（非 curl 可判斷），是下一步的具體待辦。
3. **市長政見兌現追蹤是最大缺口**：官方僅新聞稿層級，無 API／資料庫；第三方無現成、持續維護的專案覆蓋本屆市長。若要做這個功能，civic-lens 幾乎得自建資料（人工蒐集政見文本＋比對市府公告），且需設計「兌現認定」的方法論與更新機制。
4. **無官方 API／開放資料授權聲明**：`gaz.tcc.gov.tw`、`www.tcc.gov.tw`、`tccvideo.tcc.gov.tw` 皆為傳統政府網站，僅供人瀏覽，無開放資料介接文件、無 Key、無明訂速率限制（意味著必須自律避免高頻爬取，且無 SLA 保證）。robots.txt 缺失代表法律上未明文禁止，但也沒有明文授權，建議civic-lens 在使用條款頁面另行確認轉載／再利用的合法邊界（此為法遵問題，非純技術缺口，建議另行諮詢或至少讀完網站的「著作權聲明／資料開放宣告」頁面，本次未讀取）。
5. **`gaz.tcc.gov.tw` vs `tcckm.tcc.gov.tw`**：兩個網域何者為現行系統、是否已遷移，本次未确認，需優先釐清避免對接錯誤／過時系統。
6. **前科（法定公開）資料源**：本次任務範圍未涵蓋此項的實測（題目提及但本次八點清單未列查證項目），若後續要做，需另外查證司法院裁判書系統／選罷法公職候選人資格公告等來源，本文件未觸及，留待下一輪調查。
7. **公司法人關聯（本人／配偶／未成年子女）**：同上，本次未查證，經濟部商工登記公示資料（如「公司登記查詢」）可能是候選來源，但涉及個資與利益揭露申報比對，需另立專題調查，本文件不涵蓋。

## 1. 中選會選舉資料庫（db.cec.gov.tw）—— 第二輪已找到真實 API

- **前端**：https://db.cec.gov.tw/ElecTable 為 Nuxt.js SPA，curl 只能拿到空殼 HTML。
- **實測方法**：本機安裝 `npx playwright install chromium`（本機原無 Playwright，已臨時安裝於 scratchpad），用 headless Chromium 攔截網路請求，找到真實資料端點；找到後改用純 curl 即可重現，**不需每次都跑瀏覽器**。
- **確認的真實端點（全部已用 curl 驗證 200 且回傳有效 JSON）**：
  - 選舉主題清單：`https://db.cec.gov.tw/static/elections/configs/ELC_subjects.json`（例：P0=總統副總統、L0=立法委員、T1=直轄市議員、T2=縣市議員…）
  - 各主題的選舉屆次清單：`https://db.cec.gov.tw/static/elections/list/ELC_{subject_id}.json`（如 `ELC_P0.json`），每筆含 `theme_id`（該屆選舉的唯一識別碼）、`vote_date`、`session`
  - 逐候選人得票資料：`https://db.cec.gov.tw/static/elections/data/tickets/ELC/{subject_id}/{legislator_type_id}/{theme_id}/{data_level}/{prv}_{city}_{area}_{dept}_{li}.json`
    - 實測樣本（2024 總統副總統選舉全國層級）回傳欄位：`cand_id`（**中選會官方候選人唯一 ID**）、`cand_name`、`cand_sex`、`cand_birthyear`、`cand_edu`、`party_code`、`party_name`、`ticket_num`、`ticket_percent`、`is_victor`、`cand_no`（號次）等，逐一列出正副總統候選人（柯文哲/吳欣盈等），資料真實且結構清楚。
  - 對應行政區資料：`https://db.cec.gov.tw/static/elections/data/areas/ELC/...`（同路徑模式，未深入解析欄位，但已確認 200）
  - 候選人附件（可能含公報/學經歷檔案索引）：`https://db.cec.gov.tw/static/elections/data/attachments/ELC/{subject_id}/{theme_id}/list.json`（已確認可達，內容未展開解析）
- **開放資料登記**：data.gov.tw dataset **id=13119**「選舉資料庫(含選舉區資料)」已用 `https://data.gov.tw/api/v2/rest/dataset/13119` 實測 200，回傳完整 metadata：
  - `license: "1"`（免費）、`updateFrequency: 每次選舉後7天`、`publisherContactEmail: kinyo222@cec.gov.tw`
  - `distribution` 內宣稱有 CSV 資源，`resourceDownloadUrl: https://data.cec.gov.tw/選舉資料庫/voteData.csv`（格式 CSV，UTF-8）
  - **此 CSV 連結實測失敗**：`curl -L` 對該 URL 產生無限重導向（50 次後放棄，`Maximum redirects followed`），判定為**目前不可程式化下載**（可能需登入頁或前端 JS 導頁），與上方 JSON 端點（已驗證可用）是兩條不同路徑，請優先用 JSON 端點。
- **結論**：#1 與 #7（候選人唯一鍵）**由「僅文件宣稱」升級為「已實測可用」**——`cand_id` 就是官方候選人唯一鍵，不需要再靠姓名＋生年模糊比對。
- **坑**：端點路徑需要先取得 `theme_id`（每屆選舉一組雜湊值，非遞增序號），必須先讀 list.json 再組出 tickets/areas 的 URL；`data.cec.gov.tw` 的 CSV 批次下載暫不可靠。

## 5. 前科揭露法源（已實測——查全國法規資料庫原文）

- **查詢工具**：`law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0020010`（公職人員選舉罷免法），實測 HTTP 200，並以 WebFetch 讀取條文內容。
- **重要結論（與一般直覺不同，需特別注意）**：
  - **選舉公報並無揭露「犯罪紀錄／前科」的條文**。第 47 條規定公報僅刊登：號次、相片、姓名、出生年月日、性別、出生地、推薦之政黨、學歷、經歷及政見——沒有前科欄位。
  - 犯罪紀錄相關規定落在**第 26 條「候選人資格限制」**：特定犯罪經判決確定者**不得登記為候選人**（資格排除，而非公報揭露義務）。
  - **結論對本專案的意義**：civic-lens 若想呈現候選人「前科」，**沒有現成的官方選舉公報前科欄位可抓**；只能：(a) 依第 26 條邏輯推論「能登記＝未達排除門檻」，或 (b) 另外整合裁判書公開資料（司法院裁判書查詢系統）並自行比對姓名/生年，這是完全不同的資料源與更高的身分比對風險（同名同姓誤判），需要在產品層面謹慎處理與免責。
- **注意**：以上第 26／47 條條號與內容為 WebFetch 對全國法規資料庫頁面的摘要整理，**建議正式引用前再人工開網頁核對條文最新版本**（法規可能修正，且 WebFetch 摘要非逐字比對）。

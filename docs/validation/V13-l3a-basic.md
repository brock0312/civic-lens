- 直排的格子（姓名、出生年月日）要依 y 排序。苗栗切出 `年44月1日13`，表示同一欄的字詞排序方式要依欄寬判斷直排或橫排。

- 合併區的檔，最左邊有一欄「選舉區別」（基隆、彰化、苗栗），用來判斷選區。

**A 家族**：沿用 `tpe_bulletin_2022.parse_bulletin()`。

- **只有新竹縣改了區域選區界線**：2022 第1區（竹北市）切成 2026 第1、2區，其餘選區內容不變、區號 +1（山地原住民 13→14）。所以「範圍重疊」是：2022 第1區 ↔ 2026 第1或2區；2022 第N區 ↔ 2026 第N+1區。
- 彰化、雲林、基隆、新竹市**新增**原住民選區，2022 沒有對應的選區，所以 2022 當選人不會落在這些新選區。其他選區號碼不變、範圍不變。
- 其餘 17 縣市（含五都）的選區號碼與範圍都相同，可以直接用「同區號」判斷是否重疊。名額改變不影響範圍。

## 建議實作順序

### 共用工作（先做，約 1–2 session）

1. **公報目錄爬蟲**：產生「檔 → 選區」對照表（§1.2）。排除罷免公告。標記合併檔與「首長與議員同檔」的檔。
2. **框線切格器**（C、D 共用）：沿用 `gridcut.py` 的想法，並加上：直排格依 y 排序、全形號次、選舉區別欄、跨頁。核對沿用臺北的三道閘門：
   - 開票 JSON 的號次、姓名、出生年、黨籍完全一致；
   - 與 `-raw` 子字串核對；
   - 圖片政見不收。
3. **開票 JSON 讀取**：用 C 層全國檔，取 `ori_area_code`，`*` 和 `!` 都算當選，金門與嘉義市的 city_code 要連同 prv_code 比對。
4. **姓名正規化**：去空白與間隔號；異體字只能拿來產生審閱候選，不能自動串接。
5. **B 家族解析**（新北、臺南）：框線切下半部，上半部依標籤切。

## 1. 要對照的政黨字串

```
$ git show HEAD:data/civic.sql > scratchpad/parties/civic.sql
$ python3 -c "from etl.db import open_db; … select json_extract(data,'$.party'), kind from fact where kind in ('candidacy','office')"
```

HEAD 版本只有 `candidacy`，共 18 個不重複值。工作目錄中未 commit 的 dump 另有 50 筆 `office`，政黨值（中國國民黨、民主進步黨、台灣民眾黨、新黨、社會民主黨）都已包含在這 18 個值之中，所以不會多出新字串。

「無」（19 筆）代表沒有政黨，不在本次範圍。其餘 17 個值見 §3。資料中**沒有**「無黨團結聯盟」與「無黨籍」。

## 2. 官方來源與法源

### 2.3 法源（全國法規資料庫實測）

```
$ curl -sS -o law2.html "https://law.moj.gov.tw/Law/LawSearchResult.aspx?ty=ONEBAR&kw=政黨法"   → 200，pcode=D0020078
$ curl -sS -o law.html -w "%{http_code} %{size_download}" \
    "https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0020078"   → 200 72809
法規名稱：政黨法　公布日期：民國 106 年 12 月 06 日
```

（注意：`pcode=D0020128` 不是政黨法，會 302 轉到 `/ErrorPage.aspx?err=901`。）

- **第 12 條第 1 項第 2 款**：政黨章程應載明「有標章者，其標章」。
- **第 13 條第 1 項**：新設立的政黨「**得**於申請政黨備案時，同時檢具標章備案申請書及**標章電子檔**，向主管機關申請標章備案」。第 2 項規定已設立政黨辦理標章備案或變更時，應檢具章程、申請書及標章電子檔。第 3 項規定申請書應載明「政黨標章圖樣」等事項。
- **第 14 條**：標章不得與已設立政黨的標章相同或近似、不得減損識別性、不得有歧視或仇恨意涵，否則不予備案。

**結論**：標章備案是「得」，**不是強制**。所以名冊上沒有圖，不代表該黨沒有黨徽，只代表沒有向內政部備案或上傳。

## 4. 使用條款（`cp.aspx?n=16099`，原文重點）

判讀：

- **沒有禁止條款**。15 個名冊頁上也沒有看到「須經同意方可使用」的特別聲明，所以依指示繼續下載。
- **授權範圍的限制**：內政部只能授權它自己擁有的著作權。黨徽是各政黨提交的著作，著作權、商標權屬於政黨。宣告第二點（一）也明確排除商標。因此，這份宣告只能證明「內政部公開了這些圖，而且沒有禁止利用」，**不能證明政黨同意重製**。本站用途是在政黨名稱旁邊顯示黨徽，幫助辨識，屬於中性指稱，不是商業使用。不過，這是否構成合理使用或商標的指示性使用，**本文件沒有結論**，建議併入 PLAN §6 第 4 點，上線前由 `security-executor` 或法務一起審查。
- **本站遵守的事項**：（1）註明出處。`index.json` 每筆都有 `source_url`，前端應在黨徽的 title 或頁尾註明「黨徽來源：內政部政黨資訊網」。（2）縮圖只做等比例縮放，不改色、不裁切、不重繪（符合第三點「禁止不當變更」、第四點「不得惡意變更」）。
- PLAN §6 第 5 點「不使用政黨背景網站」：本次只用內政部網站，沒有使用任何政黨官網。

## 5. 後續維護

- 名冊頁的標章可能會更新（例如時代力量在 2025 年換新標章）。建議在每次發布前，對 15 個 `source_url` 重新抓取 `party_emblem` 的 `src`，和 `index.json` 的 `image_url` 比對。如果不同，就重新下載。
- 如果之後有新政黨字串（例如公報上網後新增），要在名冊列表逐字比對；比對不到就不放圖。

# civic-lens

讓台灣選民輸入所在地，就能看清楚自己選區的民意代表與首長「做了什麼、說過什麼、跟誰有關」。

> 狀態：**建置中**。臺北市的名單、選區、書面質詢、口頭質詢影片已完成。計畫見 [`docs/PLAN.md`](docs/PLAN.md)，資料來源調查見 [`docs/data-sources/`](docs/data-sources/)，驗證紀錄見 [`docs/validation/`](docs/validation/)。

## 目標

使用者輸入地址或行政區後，儀表板顯示該選區的**區域立委、縣市議員、縣市長**（現任與 2026 候選人），並提供：

| # | 功能 | 內容 |
|---|------|------|
| G1 | 出席紀錄 | 院會／大會、委員會出席與請假 |
| G2 | 質詢紀錄 | 質詢次數、對象、主題，**附原始質詢影片連結**（立法院 IVOD、議會影音） |
| G3 | 會議表現 | 提案、連署、表決紀錄 |
| G4 | 政見與兌現 | 選前政見（選舉公報）對照任內已實現事項 |
| G5 | 前科 | 僅限法定公開資料（見下方資料邊界） |
| G6 | 公司法人關係 | 本人及法定相關人財產申報中的公司持股，對照商工登記董監事（僅涵蓋申報資料可及範圍，見 PLAN §6） |

## 已定案的決策（2026-09-28）

- **範圍**（2026-09-30 更新）：全國 22 縣市全功能，涵蓋立委、縣市長、縣市議員，首頁從台灣地圖進入。
  - **11/07 前**：全國名單與選區上線，臺北深度資料持續補齊。
  - **之後**：逐一打通各議會的資料系統（六都優先），打通一個上線一個。
  - **尚未打通的縣市**：頁面標示「深度資料建置中」，並連到外部資源。
  - 原本的決策是「縣市先以臺北試點」。
- **對象**：現任 + 2026-11-28 地方選舉候選人。新人沒有任內紀錄，只顯示公報政見、學經歷與法定揭露事項，並明確標示「無任內紀錄」，不能讓空白看起來像表現差。
- **資料邊界：只用法定公開資料**
  - 前科：只用司法院**已確定**的判決，而且必須能佐證身分（選舉公報依法**不**刊登前科，見選罷法第 47 條）。
  - 相關人：只包含本人，以及財產申報中列出的配偶、未成年子女。
  - 不做推論、不收媒體傳聞、不擴及其他親屬、不收政治獻金捐贈者網絡。
  - 例外說明：`data/identity.csv` 有 3 筆身分對照引用新聞報導，僅用來佐證「同名、同選區的登記者就是現任議員」，新聞內容本身不會顯示在網站上。
- **外部參考資源：只放連結，不轉載資料**（2026-09-30）
  - [council2026.taiwangogo.tw](https://council2026.taiwangogo.tw/)（前科資料庫）：只放網站層級的連結，並附揭露式聲明。聲明要寫明三件事：
    - 經營者是台灣前進，網站由時代力量代管，並與時代力量、台灣基進、台灣綠黨、小民參政歐巴桑聯盟合作。
    - 收錄範圍包含起訴、行政罰、民事判決與新聞報導，而起訴不等於有罪。
    - 本站未查證其內容。
  - [報導者觀測站](https://lawmaker.twreporter.org/)：放個人頁的深連結，議題名稱與相關提案數原文照錄並標示出處。依 CC BY-NC-ND 3.0 TW，不改寫、不摘要。
- **每一筆資料都附原始出處連結與擷取時間**；遇到同名而無法唯一確認身分時，不顯示。

## 非目標

- 評分、排名、政治立場判斷（只呈現事實與出處，不下結論）
- 鄉鎮市長／代表、村里長
- 使用者帳號、留言、社群功能
